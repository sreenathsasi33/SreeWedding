# Sreenath & Ashitha — Wedding Reception Invitation

Groom's-side digital wedding reception invitation website for **Sreenath & Ashitha**, built with modular HTML, CSS, and vanilla JavaScript for **GitHub Pages**.

## Expected Live URL
`https://sreenathsasi33.github.io/wedding-invitation/`

## Publishing to GitHub Pages
1. Create a new repository named `wedding-invitation` under GitHub account **`Sreenathsasi33`**.
2. Upload the contents of `Sreenath_Ashitha_Reception_Invitation/` (`index.html`, `css/`, `js/`, `assets/`) to the root of the repository.
3. Go to **Settings -> Pages**.
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**, select `main` and `/(root)`, then click **Save**.
5. Wait 1–2 minutes and open `https://sreenathsasi33.github.io/wedding-invitation/`.
