# Sreenath & Ashitha — Wedding Reception Invitation

Traditional Kerala Hindu digital wedding reception invitation for **Sreenath & Ashitha**, featuring a luxury midnight-and-champagne-gold starlit welcome screen, scroll-driven palm leaf manuscript (*Thaliyola*), bilingual English/Malayalam support, and instant attendance confirmation.

## Expected Live URL
`https://sreenathsasi33.github.io/wedding-invitation/`

## Updating Your GitHub Repository
1. Extract `Sreenath_Ashitha_Reception_Invitation_v3.zip`.
2. Open `https://github.com/Sreenathsasi33/wedding-invitation` on branch `main`.
3. Click **Add file -> Upload files** and upload the contents of `Sreenath_Ashitha_Reception_Invitation/` (`index.html`, `css/`, `js/`, `assets/`, `README.md`) to the root of the repository.
4. Click **Commit changes** and wait 1–2 minutes for GitHub Pages to redeploy.
